# English Practice App

A Flutter application designed to help users practice and improve their English language skills through interactive features.

## Features

*   **Vocabulary Builder:** Browse a list of English words complete with definitions and practical example sentences to improve your vocabulary.
*   **Grammar Quizzes:** Test your English grammar and vocabulary knowledge with interactive multiple-choice quizzes that provide immediate feedback and track your score.
*   **Responsive Design:** Fully responsive layout that looks great on mobile, tablet, desktop, and web browsers.

## Tech Stack

*   Flutter
*   Dart
*   Material Design 3

## Getting Started

1.  Make sure you have [Flutter](https://flutter.dev/docs/get-started/install) installed.
2.  Clone this repository.
3.  Run `flutter pub get` to fetch dependencies.
4.  Run `flutter run` to launch the app on your preferred device or emulator.
